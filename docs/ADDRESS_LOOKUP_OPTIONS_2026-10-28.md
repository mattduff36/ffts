| Option | Fit for FFTS | Cost and limitations |
|---|---|---|
| Geoapify hosted search | Practical business/place and address autocomplete using open data. Coverage must be checked against the client's actual sites. | Free plan: 3,000 credits/day, 5 requests/second, no credit card required; commercial use allowed with attribution. Not itself an open-source hosted service. See [pricing](https://www.geoapify.com/pricing/) and [credit details](https://www.geoapify.com/pricing-details/). |
| Photon | Open-source Apache 2.0 geocoder with search-as-you-type based on OpenStreetMap. | Software is free; self-hosting needs infrastructure and maintenance. Public demo has reasonable-use limits and no availability guarantee, so it is unsuitable as a guaranteed production dependency. See [official project](https://github.com/komoot/photon). |
| Nominatim public service | Explicit address-search button could work; unsuitable for autocomplete. | Public policy caps aggregate usage at 1 request/second and prohibits client-side autocomplete. Attribution, identification and other restrictions apply. See [official usage policy](https://operations.osmfoundation.org/policies/nominatim/). |
| Postcodes.io | Useful free postcode validation/location helper. | Open-source MIT service; it does not supply a business-name or complete street-address directory. See [official site](https://postcodes.io/). |
| Google Places | Strong candidate for business-name selection and structured address details. | Billing must be enabled. Global USD pricing: Autocomplete Requests has 10,000 free events/month, then $2.83 per 1,000 up to 100,000; Place Details Essentials has 10,000 free/month, then $5 per 1,000. Geocoding has the same 10,000/$5 tier. Place Details Pro has 5,000 free/month, then $17 per 1,000. Requested fields and autocomplete-session handling affect the SKU and cost. Small usage may remain free, but enabling billing is still a paid-provider decision. Owner approval required before enabling. See [official pricing](https://developers.google.com/maps/billing-and-pricing/pricing) and [Places billing](https://developers.google.com/maps/documentation/places/web-service/usage-and-billing/). |
| what3words | Useful supplementary precise entrance/location reference. | Not a replacement for business search or postal address completion. Coordinate conversion is paid; free AutoSuggest alone does not complete this workflow. See [plans](https://accounts.what3words.com/select-plan?platform=website) and [API documentation](https://developer.what3words.com/public-api/docs). |

No provider account, key, paid subscription or integration has been created. Prices and quotas should be rechecked when choosing a provider. Free hosted tiers still require attribution, acceptable-use compliance and monitoring; self-hosted open-source software still has hosting costs.
