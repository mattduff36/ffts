# Forest Farm Tree Services logo pack

Source: https://www.forestfarmtreeservices.co.uk/wp-content/uploads/2017/05/forest-farm-tree-services-300x88.png

The untouched 300 x 88 original is included. The original-derived variants preserve its artwork. The separately named `logo-centered-dark` and `app-icon-centered-source` are AI-assisted redesigns based on the owner's centred mockup, with the leaf behind the wording. SVG files are self-contained containers embedding the original raster artwork, not newly traced vectors. Enlarged PNGs do not add original detail; obtain the original vector artwork for large-format print.

- `logo-light`: original colour leaf and dark lettering, transparent background; light pages and PDF documents.
- `logo-dark`: original horizontal leaf and white lettering, transparent background; retained for existing usage.
- `logo-centered-dark.png` / `.webp`: centred login redesign, white wording over the leaf, transparent background. The WebP is used by the login screen; PNG is included for reuse. This asset is maintained separately and is not regenerated by the source-logo script.
- `logo-monochrome-white` / `logo-monochrome-black`: single-colour silhouettes.
- `leaf-transparent`: original leaf alone with transparency.
- `leaf-on-light` / `leaf-on-dark`: square app marks with contrasting backgrounds.
- `app-icon-centered-source.png`: approved-theme app icon master, green leaf behind white FFTS on charcoal.
- `ios-app-icon`: derived app mark used for every Apple touch icon size. Android 192/512 variants share the same master; the maskable icon adds safe-zone padding.
- `icon-16/32/48/192/512.png`: browser and PWA sizes.
- `icon-maskable-512.png`: opaque PWA icon with a protected central safe zone.
- `social-card.png`: 1200 x 630 Open Graph / Twitter sharing image.
- `favicon.ico` / `favicon.svg`, Apple touch icons and PWA icons: browser/install assets.

Palette: accent #a0d06d, dark canvas #131614, light icon background #f5f7f1. Cards and tables remain neutral charcoal.

Regenerate with `node scripts/branding/build-logo-pack.mjs`. Established `/images/forest-farm/` logo URLs also serve the actual artwork for configured app/PDF consumers. The private app's robots policy is unchanged.
